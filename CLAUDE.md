# Clube do Livro — instruções para o Claude Code

Siga [`AGENTS.md`](AGENTS.md), que vale para todos os agentes. Em resumo:

- Leia `docs/mapa/mapa.json` antes de começar; é o cérebro compartilhado com o Codex.
- Ao terminar uma tarefa, registre a entrega no topo de `atualizacoes`, revise o estado, rode `npm run mapa:check` e `npm run mapa`, e inclua o mapa no PR.
- Entregue ao dono o link https://layonlad.github.io/Aplica-o-Clube-do-Livro/mapa/ no resumo final.
- Visual e componentes seguem `docs/DESIGN_SYSTEM.md`.
